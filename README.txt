เว็บไซต์คู่มือครูฝึกทหารใหม่ — กองพลทหารภูเขาที่ ๑ (หน่วยสมมติ)

ไฟล์ในชุด:
- index.html: เนื้อหาเว็บไซต์
- style.css: รูปแบบและการแสดงผลบนมือถือ/คอมพิวเตอร์
- script.js: บทเรียน 7 วัน แบบประเมิน บันทึกในเบราว์เซอร์ และส่งออก CSV

วิธีเปิดทดสอบ:
1. แตกไฟล์ ZIP
2. เปิด index.html ด้วยเบราว์เซอร์

วิธีเผยแพร่ด้วย GitHub Pages:
1. สร้าง repository แบบ Public
2. อัปโหลด index.html, style.css, script.js และ README.txt ไปที่ root ของ repository
3. กด Commit changes
4. ไปที่ Settings > Pages
5. ใน Build and deployment เลือก Deploy from a branch
6. เลือก Branch: main และ Folder: / (root) แล้วกด Save
7. รอสักครู่แล้วเปิด URL ที่ GitHub Pages แสดงให้

หมายเหตุ:
- ข้อมูลแบบประเมินเก็บไว้ใน localStorage ของเบราว์เซอร์บนอุปกรณ์นั้นเท่านั้น ไม่ได้ส่งไปยังครูฝึกคนอื่นหรือฐานข้อมูลกลาง
- หากเปิดบนอุปกรณ์อื่น จะไม่เห็นข้อมูลที่บันทึกไว้จากอุปกรณ์เดิม
- เว็บไซต์นี้เป็นต้นแบบสำหรับหน่วยสมมติ ไม่ใช่ระบบหรือหลักสูตรทางการของกองทัพไทย
